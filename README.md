# Medoc

Logiciel hybride de gestion physique et électronique de documents.

## Installation

1. Téléchargez le fichier `medoc-windows_X.X.X.exe`.
2. Double-cliquez dessus pour lancer l'installation.
3. Suivez l'assistant en cliquant sur **Suivant** à chaque étape, comme pour n'importe quel logiciel.

À la fin de l'installation, votre navigateur s'ouvre automatiquement :

1. Remplissez le formulaire d'inscription.
2. Choisissez **« Je n'ai pas de licence »**.

## Période d'essai

- Pendant un mois, vous avez accès à toutes les fonctionnalités.
- Après ce délai, le logiciel **ne se bloque pas** et reste utilisable, mais avec les limitations suivantes :

| Fonctionnalité | Version limitée |
|---|---|
| Logo | Personnalisation du logo non disponible |
| Fonds | 1 fonds |
| Sites | 1 site |
| Importation de données | Limitée |
| Taille des fichiers | 200 Mo maximum par fichier |
